# Maquettes MediBet

Maquettes statiques des 12 écrans principaux de MediBet, au même style visuel
que `medibet.html` (thème sombre, doré, polices Monoton / IBM Plex). Ce sont
des pages HTML autonomes, sans logique JS — à ouvrir directement dans un
navigateur, ou à utiliser comme référence pour recréer les écrans dans Figma.

| Fichier | Écran |
|---|---|
| `00-accueil.html` | Accueil — choix du rôle (Patient / Médecin / Proche) |
| `01-patient-mes-dossiers.html` | Patient — mes dossiers |
| `02-patient-symptomes.html` | Patient — choix des symptômes |
| `03-patient-dossier-pari.html` | Patient — dossier et pari (cotes, mise, proches) |
| `04-proche-rejoindre.html` | Proche — rejoindre un pari avec un code dossier |
| `05-classement-patients.html` | Classement des patients (CoinPot) |
| `06-medecin-dossiers-diagnostic.html` | Médecin — dossiers en attente + diagnostic officiel |
| `07-resultat-booster.html` | Résultat du pari + ouverture d'un booster de cartes |
| `08-collection-cartes.html` | Collection de cartes maladies par rareté |
| `09-recyclage-cartes.html` | Atelier de recyclage des doublons de cartes |
| `10-classement-medecins.html` | Classement des collègues (médecins) |
| `11-console-fhir.html` | Console FHIR — journal des appels réseau |

Version éditable (canvas multi-écrans, export PNG/PDF) :
